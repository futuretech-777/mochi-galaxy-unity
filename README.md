# 🧸 Mochi Galaxy Unity

3D Multiplayer Mascot Controller, Network Management, and Custom Shader Guides for Unity.

## 📦 Contents

- **`MochiCharacterController.cs`**: 3D character controller handling movement, jumping, squish/stretch animations, and physics.
- **`MochiNetworkManager.cs`**: Photon Network multiplayer manager handling room connections, player spawning, and synchronization.
- **`MochiModelSettings.cs`**: ScriptableObject configuration for customizable mascot attributes (speed, jump force, squish dynamics, materials).
- **`PastelGlow_ShaderGuide.md`**: Guide for implementing pastel aesthetic lighting, rim lighting, and custom shaders.
- **`UnityAssemblyGuide.md`**: Step-by-step instructions for assembling the 3D mascot prefab and setting up the multiplayer scene in Unity.

## 🚀 Getting Started

1. Import these scripts into your Unity project's `Assets/Scripts` folder.
2. Follow the setup steps in [UnityAssemblyGuide.md](UnityAssemblyGuide.md).
3. Configure shaders and lighting following [PastelGlow_ShaderGuide.md](PastelGlow_ShaderGuide.md).
